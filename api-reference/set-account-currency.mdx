---
title: "Change the Account Currency"
openapi: "openapi.yaml PUT /api/v1/merchant/account-currency"
playground: "none"
---

<Note>
A dashboard endpoint: it uses the signed-in dashboard session, not an API key, and requires the Owner or Admin role. The currency can change at any time; a balance in the previous currency stays payable in it and can be [converted](/api-reference/convert-balance). See [settlement and your Account Currency](/guides/settlement#choosing-your-account-currency).
</Note>

| HTTP | `code` | When |
| --- | --- | --- |
| 400 | `invalid_account_currency` | The currency is not one of CHF, EUR, USD and GBP, or Qint has switched it off. |
